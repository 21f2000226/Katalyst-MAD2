# Katalyst frontend

Vue 3 , Vite and Bootstrap SPA for the Katalyst V 2 placement portal.

## Run (from this folder)

```powershell
npm install
npm run dev
```

Dev server: http://localhost:5173 (API is running on → `http://127.0.0.1:3000`)

```powershell
npm run build
```

Built files go to `dist/`. Flask in `../backend` serves them when you run `python app.py` there.
